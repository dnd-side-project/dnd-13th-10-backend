### 🤔 기획 배경

---
기존의 면접 회고는 템플릿 없이 막연한 메모장 형태로 기록되거나, <br> 작성 후에도 체계적으로 관리하기 어려워 <br>
사용자들이 회고를 이어가기 힘들었어요. <br><br> 
이러한 문제를 해결하기 위해, <br>
회고를 쉽고 빠르게 작성하고 <br>
한눈에 모아 관리할 수 있는 SEED를 기획하게 되었어요.
